## 📖 Overview
**Thumb Fighter** is a local head-to-head multiplayer iOS game designed to test your reflexes. Developed as part of the Apple Developer Academy journey, two players share a single screen and compete using rapid "tap-tap" mechanics and strategic power-ups to overpower each other in a virtual thumb wrestling match.

## ✨ Key Features
* **Single-Device Multiplayer:** Face off against a friend simultaneously on one iPhone screen.
* **Rapid-Tap Mechanics:** Highly competitive, reflex-based gameplay relying on tap speed to drain your opponent's stamina.
* **⚡ Special Power-Ups:** Dynamically spawning power-ups that temporarily boost your tapping strength, freeze your opponent, or restore stamina, adding strategic depth to the frantic tapping.
* **Haptic Feedback:** Integrated custom haptics for every tap, collision, and power-up collection to ensure physical interactions feel punchy and responsive.
* **Modern UI Architecture:** Clean game logic and user interface constructed iteratively using 100% SwiftUI.

## 🛠 Tech Stack
* **Language:** Swift
* **UI Framework:** SwiftUI
* **Hardware Integration:** Core Haptics
